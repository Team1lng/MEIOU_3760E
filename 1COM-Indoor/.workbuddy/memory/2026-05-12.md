# 2026-05-12 工作日志

## 系统时间漂移补偿方案

### 问题背景
- 无网络环境下屏幕时间显示偏差，需要测量漂移并做补偿
- 屏幕只显示时分，无秒数

### 已实施修改

1. **`src/layout/layout_standby.c`**（~第960行）
   - 在 `standby_time_display_task` 里每分钟打印一次 `[TIME_DRIFT] 日期 时:分:秒`
   - 用于长时间放置后对比实际时间，计算漂移率

2. **`src/layout/layout_setting_sys.c`**（`sys_rtc_time_set`，~第249行）
   - 手动设置时间时强制 `date->tm_sec = 0`，确保基准是整分钟

3. **`src/layout/layout_setting_sys.c`**（顶部新增）
   - 新增 `time_calibrate_task()`：每分钟被调用，每 4 小时触发一次漂移补偿
   - `TIME_DRIFT_COMPENSATION_SEC`：填测出来的补偿秒数（正=系统偏慢，负=系统偏快），目前填 0（禁用）
   - 使用 `CLOCK_MONOTONIC` 计时，`settimeofday()` 写时间，`hwclock -w` 同步 RTC
   - 补偿后打印 `[TIME_CAL]` log

4. **`src/main.c`**（`hardware_detect_task` 后）
   - 创建 `time_calibrate_task` lv_task，周期 60 秒，`clean_lock = false`
